Welcome. This is the first post on my site.

I'll use this space to write about things I'm building, things I'm learning,
and the occasional note-to-self that might be useful to someone else.

To add a new post, create a Markdown file in `src/content/posts/`. The filename
becomes the URL slug.

## Frontmatter fields

- `title` — required
- `description` — required, shown in lists
- `date` — required
- `draft` — optional, set `true` to hide from the site
- `tags` — optional array

That's it.
